ROTATION

10   Optimizing the rotational loss

10.1   Marginal loss

We will now find the thrust distribution which minimizes the rotational loss for a given overall thrust and the local and overall efficiency, by the method of "constant marginal loss".

  The rotational momentum loss ratio (9.3) and the efficiency (9.4) vary along the blade, with the local pitch angle. Intuitively, we can move thrust from a radius with low efficiency to one with high efficiency, making the whole propeller more efficient.

  By inspection of (9.4), we can make the efficiency the same everywhere by scheduling b (x) with cos2 φ. We will find below that this is in fact the optimal solution.

  But having the same efficiency everywhere is not formal proof of optimality. The formal proof requires that we make the marginal efficiency the same everywhere. This is not the same thing.

  A small change in the local thrust dT, or better a small change in the net power dT . V, will cause a small change in the local power loss. The ratio between this extra power loss and the extra net power is called the marginal loss.

  As long as the derivative of dPm with respect to dT is not the same everywhere, we can gain efficiency by taking in­cre­ments of thrust away from locations with high marginal loss, and moving thrust to locations with low marginal loss. We will stop moving thrust only when the derivative has reached the same value everywhere, i.e. when the marginal loss has the same value everywhere. We will call this constant marginal loss ratio C :

d ( d P m ) d ( d T  .  V ) = C (10.1)

The inner "d" 's indicate ring values, the outer "d" 's are the symbols for the derivative.

  Since we are not varying flight conditions like ρ or V, or any propeller geometrical parameters like R or X, then by (3.9) we can write the same equation in non-dimensional form :

d ( d P m ′ ) d ( d T  ′ ) = C (10.2)

The ring thrust dT ′ is the variable driving the change. We could express dPm ′ as a function of dT ′, and take the derivative of dPm ′ with respect to dT ′ directly.

  But it is easier to use the local value of the induction ratio b (x) as the variable driving both dT ′ and dPm′.

The marginal loss then becomes :

d ( d P m ′ ) / d b   d ( d T  ′ )   / d b = C (10.3)
